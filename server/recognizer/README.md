# 命盘背包截图识别器

《龙族：卡塞尔之门》精神命盘「物品详情」弹窗截图 → 结构化库存数据。

## 文件

| 文件 | 说明 |
|---|---|
| `recognizer.py` | 识别模块（唯一代码文件，无第三方服务依赖） |
| `tpl-data.json` | 角色头像模板库：113 个 48×56 模板，覆盖背包固定顺序的 58 个物品（双渲染版本） |
| `digit-lib.json` | 数字样本库：117 个 16×26 二值样本，用于数量 OCR |

三个文件必须放在同一目录。

## 依赖

```
pip install pillow numpy
```

## 使用

作为模块引入：

```python
from recognizer import recognize

cells = recognize('IMG_6064.PNG')
# None  → 截图中没有找到「物品详情」面板
# 否则返回格子列表（空格子自动跳过）：
# {
#   'row': 1, 'col': 2,          # 格子位置（1 起）
#   'name': '影镰恺撒',           # 58 个背包物品名之一
#   'count': 4,                  # 数量；提取失败为 None
#   'name_confident': False,     # 名称低置信 → 需人工确认
#   'count_confident': False,    # 数量低置信 → 需人工确认
#   'mse': 707.0, 'gap': 54.0,   # 名称匹配分数 / 与次优差距（调试用）
#   'cc': 0.77                   # 数字置信度（调试用）
# }
```

命令行：

```bash
python3 recognizer.py IMG_6064.PNG [更多截图...]
```

## 置信度规则（内置）

- 名称低置信：`gap < 100` 或 `mse > 900`
- 数量低置信：`cc < 0.85` 或 `count is None`

实测（2026-09-03，5 张真实截图共 97 格）：名称原始准确率 96%，数量 82%；
所有错误均被上述规则标出，按 `*_confident` 字段过滤/高亮即可，不会静默填错。

## 算法管线

1. **面板定位**：亮灰低饱和区域行列投影 → 「物品详情」面板边界
2. **网格定位**：面板左上 + 固定偏移 (60,26)px（原生分辨率），4×5 网格，列距 182.3 / 行距 153.5px，随面板缩放
3. **空格子检测**：格子区饱和度像素占比 < 5%
4. **名称匹配**：半分辨率 + 搜索窗外扩 16px（容忍滚动偏移），截尾加权 MSE（脸部区权重 2.5、数字区权重 0、去掉误差最大 15% 像素），粗搜 step2 + ±2 精修
5. **数量 OCR**：白字 + 深色描边邻域提取 → 连通域合并 → 按数字底/右缘自锚定，17px 间距从右往左切片（1~3 位）→ 归一化 16×26 与样本库做 NCC 最近邻

## 已知边界

- 绑定当前游戏版本截图几何（2796×1290 弹窗）；其他分辨率按面板比例自适应，但渲染大改需重裁模板
- 金色图标有动态流光，不同时间截图渲染有差异 → 模板库带双版本（era1/era2）；未来版本可在 `tpl-data.json` 追加模板
- 滚动幅度过大的截图会整批低置信，属正常兜底
